The dock holds the controls. It isn't one.

The keycap's edge is not decoration — it is a promise that the thing moves when you push it. Put that edge on the dock and the dock is lying. So the edge stays exclusive to buttons, and the dock has to match by sharing everything else: opaque fills, hairline borders, honest light, no gloss, no blur. Five containers built that way, each one live — click a dock to engage its sheet, flip the theme.

Has an edge — and means it

A control. The 1.5px edge under the cap is spent the instant you press: it drops, the edge vanishes, the thing has moved. The edge is the button's whole vocabulary.

Never gets one
Search apps, or talk to Frieren…

A container. Nothing happens when you push a dock, so it may not advertise a press. It belongs to the same system through material — flat opaque fill, one hairline, light from above — and through what it refuses.

What's held constant

Only the container changes

Everything inside the dock is identical in all five stages, so the comparison is honest. The search field is a solid inset box, the agent keeps its spinning presence ring, and the app icons take a 1px settle and a slight dim when clicked — never the button's hard edge. They are pictures you click, not caps you press, and the difference should be visible at a glance.

Every variant also drops backdrop-filter entirely. Blur is the one thing the keycap language has no answer for: it makes a surface borrow its colour from whatever is behind it, which is the opposite of an object made of something.

The dock is a sheet

Sheet

Same material, different physics. Matte opaque stock, one hairline, and a purely diffuse shadow — the thing floats, so it casts softness, never a hard line. That is the whole separation: a control has a crisp edge because it sits on something; a sheet has a blur because it sits above it. Nothing about it invites a press.

Why it fits

The safest reading of the brief. It shares the button's palette, hairline and opacity, and differs exactly where it must: hard edge versus soft shadow.

Best legibility of the five — the sheet is a real page, so app names, rows and the transcript all sit on solid white or solid near-black.

Where it hurts

Two white rectangles on a desktop: it can read as a second window rather than as chrome, especially when a window sits behind it.

It's the least characterful. Correct, calm, and not memorable.

The delta

/* app.css:694 — the shared glass rule */
- backdrop-filter: blur(22px) saturate(180%)
- background: linear-gradient(180deg, sheen…)
- inset rim / bounce / edge
+ background: var(--window-bg);
+ border: 1px solid var(--rule);
+ box-shadow: 0 2px 8px rgb(0 0 0/.1),
+   0 14px 36px rgb(0 0 0/.26);

  --dock-radius: 13px;  /* was 22 */
   no new tokens
The dock is a recess

Tray

Invert the depth and the confusion becomes structurally impossible. A button comes out of the surface; the tray goes into it — a shallow well with a shadow along its top wall, a lit lip along the bottom, and no outer shadow at all, because a hole doesn't float. The icons sit in it the way tools sit in a drawer.

Why it fits

The cleanest answer to your objection. Out means control, in means container — one lighting model, two opposite readings, nothing to learn.

It gives the field somewhere to belong: a slot inside a well is coherent, where a slot inside a floating pill was always slightly arbitrary.

Where it hurts

A recess implies a wall to cut into, and the wallpaper is a photograph. The illusion is decent on a gradient and gets weaker on a busy image.

The well is darker than the desktop chrome around it, which draws the eye downward more than an ambient element should.

The delta

/* bar + sheet */
+ background: var(--well);
+ box-shadow:
+   inset 0 2px 4px rgb(0 0 0/.16),
+   inset 0 -1px 0 var(--well-lip);
- box-shadow: 0 12px 32px …   /* no lift */

+ --well       /* #dedeD9 / #131314 */
+ --well-lip   /* the far wall catching light */
The dock is a plane

Ledge

Stop being an object entirely. The dock becomes a plane of the room: flush to the bottom, edge to edge, defined by a single hairline and a flat fill — no rounding, no lift, no shadow. You cannot press a wall, so nobody will try. It is the strongest possible statement that this is architecture and the buttons are furniture.

Why it fits

Zero object-ness. Nothing here reads as pressable at any size, and the keycap buttons in the window become the only raised things on screen — which is the point.

The sheet stops being a separate card: the plane simply grows taller, so engaging has no second shadow, no second border, no stacking.

Where it hurts

It brings back the dock's tax. The omnibar doc deliberately threw away reserved layout space, and a permanent full-width band argues for it again.

It's the most conventional-desktop look of the five — closer to a taskbar than to anything Frieren has been.

The delta

/* .frn-dock — app.css:670 */
- left: 50%; bottom: 20px;
- transform: translateX(-50%);
- width: var(--frn-dock-width);
+ inset: auto 0 0 0;
+ gap: 0;

/* bar + sheet */
+ background: var(--plane);
+ border-top: 1px solid …;
  border-radius: 0;

   the app-count width calc goes away
The dock is a boundary

Outline

At rest, the dock is a drawn line and nothing else. No fill, no shadow — just the hairline the button already uses, holding contents that carry their own solidity. Then engaging earns a real surface: the sheet arrives as opaque stock. The engagement model becomes a material fact — ambient is a drawing, engaged is a page.

Why it fits

The lightest permanent element possible while still being visible — which is exactly what the doc asks of the resting pill.

Its one borrowed detail is the hairline, so it matches the button through the button's quietest feature rather than its loudest.

Where it hurts

A hairline over a photograph is fragile. On a light wallpaper the outline needs a darker rule, so the token has to adapt to the desktop, not just the theme.

Two visual languages in one component: outline at rest, sheet when open. Defensible, but it is a rule to remember.

The delta

/* bar — the resting pill */
+ background: none;
+ border: 1px solid var(--boundary);
+ box-shadow: none;

/* sheet — the engaged surface */
+ background: var(--window-bg);
+ box-shadow: 0 14px 36px rgb(0 0 0/.26);

+ --boundary  /* hairline over wallpaper */
   icons gain their own drop shadow
The dock is atmosphere

Underlay

Delete the container. There is no bar — only a field, some icons and the agent, sitting directly on the desktop over a soft darkening of the wallpaper's lower edge. A flat gradient, not a blur: the desktop dims toward the bottom the way a room does, and the contents read against it. Nothing can be mistaken for a control because there is no surface left to mistake.

Why it fits

The furthest from a button it is possible to get — and it makes the app icons the heroes, which is what a launcher should do.

It also frees the sheet to be exactly as tall as its content with no box to fill, and the engaged desktop dim already in the design has somewhere to live.

Where it hurts

Legibility rests entirely on the scrim. Over a pale wallpaper the app labels need their own treatment, and the current white-on-scrim will not survive every image.

Losing the boundary loses the target: the "click anywhere on the pill to focus" affordance has no visible extent any more.

The delta

/* bar + sheet stop being surfaces */
+ background: none; border: 0;
+ box-shadow: none;

/* the desktop carries the scrim */
+ .frn-desktop::after {
+   inset: auto 0 0 0; height: 190px;
+   background: linear-gradient(to top,
+     var(--scrim), transparent);
+ }
+ --scrim; icons take a drop shadow

If it were mine

Tray. It is the only one that solves the problem structurally rather than by avoidance: out is a control, in is a container, and that reading holds at any size, on any surface, for anyone — no convention to learn. It also gives the search field a reason to be inset, which nothing else does. Two new tokens and the shared rule inverts.

Sheet if you want no argument — it is materially correct, changes nothing about layout, and its only fault is being unmemorable. Underlay if you're feeling brave: it is the most beautiful of the five and the most fragile, and it would need real work on legibility over arbitrary wallpaper before it could ship.

Whichever wins, the rule is the durable part: a hard offset edge means it moves when you push it. Nothing else in the system may borrow it.
