Capability subsystem · execution plan

Build it in eleven TDD slices

Each slice is self-contained, independently mergeable, and verified red → green before the next. Five build the package primitives, two re-seat the kernel, four migrate the host and land the file-watch feature. Nothing is shipped, so every slice deletes the old path it replaces — no compatibility shims.

Working rules

  • Red → green. Write the failing test first (the snippets below are the seed), make it pass with the minimum, then refactor.
  • Isolation. A slice touches only its own files + tests; package primitives are tested with fakes (no frieren, no real sockets).
  • Done = the whole suite green: pnpm format && pnpm typecheck && pnpm lint:fix && pnpm test, plus the slice's named test.
  • No back-compat. Slices 7 & 9 remove capabilityInvoke/Stream and the host if-chains outright.

Design rationale lives in docs/app-capability-system-plan.html; this doc is only the how-and-in-what-order.

Order & dependencies

Solid = build order within a lane; dashed = hard cross-lane dependency. Lanes Primitives and Kernel are independent and can proceed in parallel; Frieren needs both.

Two shared test helpers (used throughout the package slices)

const call = (capability: string, method: string, input: unknown, x?: Partial<CapabilityCall>): CapabilityCall =>
	({ appId: 'app', capability, method, input, scopes: [], ...x })

// an in-memory Channel pair — the only "transport" the proxy tests need
function pair(): [Channel, Channel] {
	const e: { rx?: (f: string) => void; close?: () => void }[] = [{}, {}]
	const mk = (me: 0 | 1): Channel => ({
		send: (f) => queueMicrotask(() => e[me ^ 1].rx?.(f)),
		onMessage: (cb) => { e[me].rx = cb },
		onClose: (cb) => { e[me].close = cb },
	})
	return [mk(0), mk(1)]
}

export interface Capabilities {
	invoke(call: CapabilityCall): Promise<unknown>
	subscribe(call: CapabilityCall, emit: Emit): Promise<Unsubscribe>
}
export type Capability = Capabilities // a unit for one name

export function capabilityRegistry(
	map: Record<string, Capability>,
	opts?: { fallback?: Capabilities },
): Capabilities {
	const pick = (c: CapabilityCall) => {
		const x = map[c.capability] ?? opts?.fallback
		if (!x) throw new CapabilityError('CAPABILITY_UNAVAILABLE', c.capability, c.method)
		return x
	}
	return { invoke: (c) => pick(c).invoke(c),
		subscribe: (c, e) => pick(c).subscribe(c, e) }
}
Done when: routing + unknown-name + fallback all green, exercised with a hand-written fake unit (no implementCapability yet).

type Ctx = { appId: string; scopes: readonly string[]; actor?: string }

export function implementCapability<C>(_contract: C, impl: Impl<C>): Capability {
	const fn = (c: CapabilityCall) => {
		const f = (impl as Record<string, unknown>)[c.method]
		if (typeof f !== 'function')
			throw new CapabilityError('CAPABILITY_UNAVAILABLE', c.capability, c.method)
		return f as (...a: unknown[]) => unknown
	}
	const ctx = (c: CapabilityCall): Ctx => ({ appId: c.appId, scopes: c.scopes, actor: c.actor })
	return {
		invoke: async (c) => fn(c)(c.input, ctx(c)),
		subscribe: async (c, emit) => (await fn(c)(c.input, emit, ctx(c))) as Unsubscribe,
	}
}
Done when: a unary fn routes via invoke(input, ctx), a Stream fn via subscribe(input, emit, ctx), unknown method throws. The kernel only ever calls subscribe for declared streams, so no runtime kind table is needed. Impl<C> derives arg types from the contract's Methods/Streams.

export interface Channel {
	send(frame: string): void
	onMessage(cb: (frame: string) => void): void
	onClose(cb: () => void): void
}
// frames: {t:'call',id,appId,capability,method,input}
//         {t:'ok',id,value} | {t:'err',id,...wire}

export function serveCapabilities(ch: Channel, local: Capabilities): void {
	ch.onMessage(async (raw) => {
		const f = JSON.parse(raw)
		if (f.t === 'call') {
			try { ch.send(JSON.stringify({ t:'ok', id:f.id,
				value: await local.invoke({ ...f, scopes: [] }) })) }
			catch (e) { ch.send(JSON.stringify({ t:'err', id:f.id, ...toWire(e) })) }
		}
	})
}
// proxyCapabilities: lazy channel + Map<id,{resolve,reject}>; a drop
// rejects all pending and the next call reopens.
Done when: round-trip + concurrency + error-frame→CapabilityError green. Scopes are not on the wire (trust note); serve fills scopes: [].

function wsChannel(ws: WebSocket): Channel {
	return { send: (f) => ws.send(f),
		onMessage: (cb) => ws.addEventListener('message', (e) => cb(e.data)),
		onClose:  (cb) => ws.addEventListener('close', cb) }
}

Sequencing notes

  • Parallelism: 1→5 (Primitives) and 6→7 (Kernel) share nothing — two people, two branches. Frieren (8→11) joins once both land.
  • First green feature: slice 11 needs only 2, 3, 7, 8, 9 — the local watch lights up before the wire protocol (slices 4, 5, 10) is even merged. If you want the demo sooner, sequence 1→2→3→6→7→8→9→11 and fold 4/5/10 in after.
  • Out of scope here: reconciling broker.ts (provider/grant capabilities) onto CapabilityError and the unit shape — a clean follow-up once the seam exists; it doesn't block any slice above.
