# Changelog

## 0.1.0

- Create a dedicated Excalidraw-backed icon editor.
- Add a fixed viewport output window on an infinite canvas.
- Make pan and zoom part of the saved icon composition.
- Preserve the user-controlled zoom when the browser window is resized.
- Add live 256px, 128px, 64px, 32px, and 16px previews.
- Add preset and custom canvas-background color controls.
- Export the visible window as exact-size PNG or SVG.
- Persist editable icon projects with optional canvas-background export.
