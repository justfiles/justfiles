Appearance → Wallpaper — four options

Same content in all four (zen colour presets · a custom colour · your own image · a live mini-shell preview) — they differ in where the preview sits and how much chrome the picker needs. Everything is live: click a swatch, pick a colour, drop an image.

Theme

A · Hero preview, then a flat picker

macOS System Settings shape: one big preview pinned at the top of the pane, then plain rows below it — swatches, custom colour, upload. No modes, no tabs; everything visible at once. Cheapest to build, closest to the existing Settings cards.

Notes / decisions hiding in here
  • The eight presets are deliberately desaturated and mid-to-dark, so white window chrome and the frosted omnibar both read against them: Ink, Graphite, Slate, Moss, Clay, Plum plus two daylight neutrals (Fog, Paper).
  • Storage: colours are a tiny JSON next to the existing image path (/system/wallpaper already holds uploaded bytes and is watched by the shell) — so both kinds sync and both apply live, with no new plumbing in the shell.
  • The preview is a dumb simulation (menubar strip + two ghost windows + a simplified omnibar pill) — never the real components. Its job is to show that windows still read on top of the colour you picked.
  • Pure flat colour is what you asked for; if a flat field feels dead, one option is an almost invisible top-to-bottom wash (≈4%) — say the word and I'll add it as a toggle.
