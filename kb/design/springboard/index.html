Five springboards

Five directions for the runner's landing page, all built on the same idea: a grid of apps you can scan in one look, and a search box that never makes you hunt for it. Same grid on a 27-inch display and on a phone — only the column count and the search placement change. v1 Daylight is the one that shipped; the rest are kept for the ideas in them. Written up in springboard.md.

Everything here is live. Type in any search box — each frame filters on its own.

The phone is not a screenshot. It is the same markup in a 390 px container, laid out by container queries.

Draw, Notes and Paint are real, straight from store.json. The other nine are stand-ins, so the grid has something to show.
